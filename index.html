Units included

UNIT 01

Algorithms & Computational Thinking

Algorithmic thinking, abstraction, decomposition, bubble sort, merge sort, linear search, binary search, algorithm efficiency, syntax errors, logic errors, testing and traceable steps.

Rules & security

Please read before starting.

01 · 60:00 TIMER

The countdown starts when the exam opens. When time reaches zero, the exam is submitted automatically.

02 · FOCUS MODE

The exam requests fullscreen. Switching tabs/windows, leaving fullscreen, losing focus, copy/cut/paste attempts, right-click, Escape or F12 are monitored as violations.

03 · 3 VIOLATIONS

At the third recorded violation, the assessment auto-submits and the report identifies that it was an automatic submission.

Important technical limitation: a browser-only HTML page cannot guarantee “no cheating” or truly disable operating-system/browser controls. Fullscreen and event detection depend on browser permissions and may sometimes count accidental focus changes. Use supervised testing for high-stakes exams.
